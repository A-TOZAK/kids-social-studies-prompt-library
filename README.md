# 子どものためのプロンプトライブラリ（社会科）

小学生が社会科の学習でAIを使うための、子ども向けプロンプトライブラリです。  
読み書きが得意な子だけが使える教材にならないように、各カードに「やさしい版」「しっかり版」「先生の見るところ」を用意しています。

## ブラッシュアップ方針

### 子ども視点の課題

- 何を書けばよいかわからない子が、最初の一文で止まりやすい。
- 空欄が多いと、学習内容ではなく入力作業でつまずく。
- AIの返事をそのまま写す使い方になりやすい。

### 教師視点の課題

- AI活用の目的が「答えを出すこと」に寄ると、社会科の見方・考え方が育ちにくい。
- 学力差への配慮がないと、支援が必要な子ほど使いにくい。
- 授業中に評価する観点が見えにくい。

### 改善したこと

- 各プロンプトに、短く始められる「やさしい版」と、考えを伸ばす「しっかり版」を追加。
- 「わからない」と書いてよいプロンプトを用意し、低学力の子や書くことが苦手な子の入口を作成。
- AIに対して、答えを丸ごと出すのではなく、問い返し・選択肢・文の型・根拠確認を促す指示を追加。
- 教師用に、カードごとの見取りポイントを追加。
- サイト内で開けるスクリーンショット付き使い方マニュアルを追加。
- フィードバック用Googleフォームを作成するGASコードを同梱。

## 使い方

1. `index.html` をブラウザで開きます。
2. はじめて使う場合は、トップの「使い方を見る」を押してマニュアルを確認します。
3. 子どもは学習場面に合うカードを選びます。
4. まずは「やさしい版」をコピーして、太字のところを自分の言葉に変えます。
5. Gemini または NotebookLM に貼り付けて使います。
6. 発表・まとめ前は「しっかり版」に切り替えて考えを深めます。

## Googleフォームの作り方

1. Google Apps Script を新規作成します。
2. `gas/create-feedback-form.gs` の中身を貼り付けます。
3. `createPromptLibraryFeedbackForm()` を実行します。
4. ログに表示される `Published URL` をコピーします。
5. `index.html` の `FEEDBACK_FORM_URL` に貼り付けます。

## GitHub Pages

GitHubに公開後、リポジトリの Settings → Pages から、`main` ブランチの root を公開元に設定するとWebサイトとして公開できます。

## 注意

AIの返答は必ず教科書・資料・先生の説明と照らし合わせて使う前提です。  
このライブラリは、答えを作る道具ではなく、問い・根拠・見直しを支援するための教材です。
