# 画像生成プロンプト集（社会科AIおたすけ）

このサイトは **画像が1枚もなくても完成して見える** ように作ってあります（ヒーローのキャラクターやアイコンはすべてコード内蔵のSVG）。
ここにあるのは「あるともっと良くなる」**おまかせの追加画像**です。生成したら、指定のファイル名で `assets/` に保存すると自動で表示されます。

## 共通のスタイル指定（全画像にこの方向を）

- テイスト: 明るくやさしいフラットイラスト。あたたかいクリーム＆水色の背景になじむ配色
- 配色: オレンジ #f5832b / 水色 #2e9ee6 / 緑 #1fae7e / むらさき #9061e0 / 黄 #ffcf3f を基調
- 線: やわらかい角丸、太めの輪郭。手描き風で親しみやすく
- 雰囲気: 小学4〜6年生が見て「自分も使ってみたい」と思える、やさしく前向きなトーン
- NG: 写実的・暗い・怖い・文字（テキスト）を画像内に入れない・特定の実在人物・ブランドロゴ
- 子どもを描く場合: 多様性に配慮（性別・髪型・はだの色をいろいろ）、表情は笑顔で安心感

> **使い方:** 下の「英語プロンプト」をそのまま Gemini / ChatGPT(DALL·E) / Adobe Firefly に貼り付け。日本語で指示したいときは「日本語プロンプト」を使ってください。Fireflyは「コンテンツの種類: アート」、縦横比を指定欄で合わせると安定します。

## 補足

- 生成画像はサイズが大きくなりがちです。保存後 `TinyPNG` などで圧縮するとページが軽くなります。
- 透過にしづらいツール（Fireflyなど）では、背景を **クリーム色 `#fff7ec`** にすると本サイトの背景になじみます。
- ヒーロー画像を置いたら、トップを開いて右側のロボットが差し替わっているか確認してください。差し替わらない場合はファイル名（`hero-kids.png`）と置き場所（`assets/`）を見直してください。
